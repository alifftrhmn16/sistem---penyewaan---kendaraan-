
# Sistem Informasi Penyewaan Kendaraan Berbasis Web

## Deskripsi
Website ini dibuat untuk memudahkan pengguna dalam melihat kendaraan dan melakukan proses penyewaan secara online.

## Fitur
- Melihat daftar kendaraan
- Melakukan penyewaan kendaraan
- Mengisi data penyewa
- Melihat informasi penyewaan
